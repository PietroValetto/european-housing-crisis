# The European Housing Crisis, Explained

Interactive maps for the Popular Economics issue *The European Housing Crisis, Explained* (https://populareconomics.substack.com/).

- `index.html` – cause-and-effect network: 74 parts and 124 links, from the forces at work to who pays.
- `map.html` – simpler problems → fixes map.
- `images/` – PNG exports.

Source: European Commission, *Understanding the housing crisis*, Staff Working Document SWD(2025) 1053, December 2025.
